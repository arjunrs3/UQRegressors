# uqregressors.bayesian.sklearn_gp

This is a compatibility wrapper of the [scikit-learn Gaussian Process Regressor](https://scikit-learn.org/stable/modules/gaussian_process.html) 
such that predictions return intervals rather than means and/or standard deviations. For more advanced use cases, the gpytorch gp implemented in gp
is more flexible. 

::: uqregressors.bayesian.sklearn_gp
